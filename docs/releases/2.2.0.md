## GartStringer 2.2

Your saved slots are safe: this version reads everything every earlier version saved, and a slot is rewritten only when you save over it. (If you ever go back to 2.1, slots saved in 2.2 will not load there.)

**A modulation matrix.** LFO twice opens MATRIX: three routes. Each route takes a SOURCE, sends it TO a destination, by an AMOUNT that can be positive or negative. K1 picks the route.

- Sources: the LFO, the filter envelope, the amp envelope, KEY (how high the note is), VELOCITY (accents), RANDOM (a new value for every note), DRIFT, and MACRO (the performance page's knob).
- Destinations: PITCH, CUTOFF, AMP, COLOUR, DETUNE, MIX.
- The LFO page still works as before; the matrix is in addition to it, so one LFO can now move several things at once.

**MIDI control.** Over USB or the MIDI IN jack, on any channel:

- Program change picks a patch, in the order PRESETS shows them. Bank select (CC 0 or 32): 0 for the first 128, 1 for the rest.
- CC 16 to 19 are K1 to K4 of whatever page is open.
- Fixed controls: 1 LFO amount, 5 glide, 12 macro, 13 DJ filter, 70 colour, 71 resonance, 72 release, 73 attack, 74 cutoff, 75 decay, 76 LFO rate, 77 drive, 78 filter envelope amount, 79 sustain, 85 drift, 86 tape, 87 crush, 88 mix, 89 sub, 91 reverb, 92 echo, 93 chorus, 94 detune, 95 echo feedback. 120 and 123 silence everything.
- Notes coming in are not played: the keys are still the only way to play.

**Fixed:** a small CPU readout was drawn over the name in the top bar on the device. It is gone; a warning now appears in the corner of the window only if the sound has actually run late.

**Checked in an emulator of the FM-1's chip** as well as the simulator: the release file boots, plays, and saves and loads a slot on both the original flash chip and the one in newer FM-1s.
